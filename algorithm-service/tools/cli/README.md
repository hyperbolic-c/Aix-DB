# Aix-DB CLI 工具使用说明

## 简介

Aix-DB CLI 是一个命令行交互工具，用于与 Aix-DB 算法服务进行交互。支持自然语言查询数据库、多轮对话、会话管理等功能。

## 架构

```
┌─────────┐  HTTP(SSE)  ┌──────────────┐  HTTP(SSE)  ┌──────────┐
│ CLI工具 │ ←─────────→ │ 后端服务     │ ←─────────→ │ 算法服务 │
│         │   流式转发   │ (FastAPI)    │   流式响应   │(Text2SQL)│
└─────────┘             └──────────────┘             └──────────┘
                               │
                               ↓ SQL
                         ┌──────────┐
                         │  SQLite  │
                         │ (chat)   │
                         └──────────┘
```

## 快速开始

### 1. 启动服务

确保算法服务已经启动：

```bash
cd /Users/liam/LLMPro/Aix-DB/algorithm-service
python -m app.main
```

服务默认运行在 `http://localhost:8002`

### 2. 运行 CLI 工具

#### 交互式模式（推荐）

```bash
python tools/cli_debug.py
```

#### 单次查询模式

```bash
python tools/cli_debug.py "查询2024年1月21日的回访量"
```

#### 指定服务地址

```bash
python tools/cli_debug.py --host http://localhost:8002/api/v1 "查询问题"
```

## 命令详解

### 基础命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/quit` 或 `/q` | 退出程序 | `/quit` |
| `/help` 或 `/h` | 显示帮助信息 | `/help` |
| `/clear` | 清屏 | `/clear` |
| `/health` | 检查服务健康状态 | `/health` |

### 调试命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/debug` | 切换调试模式（显示详细日志） | `/debug` |
| `/raw` | 切换原始 JSON 模式 | `/raw` |

### 会话管理命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/new` | 创建新会话 | `/new` |
| `/sessions` 或 `/list` | 列出所有会话 | `/sessions` |
| `/switch <id>` | 切换到指定会话 | `/switch 1` |
| `/history` | 显示当前会话历史 | `/history` |
| `/clear_history` | 清空当前会话历史 | `/clear_history` |
| `/delete <id>` | 删除指定会话 | `/delete 2` |
| `/rename <title>` | 重命名当前会话 | `/rename 工单分析` |

## 事件类型说明

CLI 工具会显示不同颜色和图标的事件：

| 图标 | 颜色 | 事件类型 | 说明 |
|------|------|----------|------|
| 🔄 | 黄色 | 步骤开始 | 处理步骤开始 |
| ✅ | 绿色 | 步骤完成 | 处理步骤完成 |
| 📝 | 青色 | SQL生成 | 生成SQL语句 |
| ⚡ | 绿色 | SQL执行 | 执行SQL查询 |
| 📊 | 蓝色 | 图表配置 | 生成图表配置 |
| 📋 | 白色 | 结果总结 | LLM生成的总结 |
| 💡 | 黄色 | 推荐问题 | 推荐的相关问题 |
| 🎉 | 绿色 | 完成 | 全部处理完成 |
| ❌ | 红色 | 错误 | 处理出错 |

## 配置选项

### 命令行参数

```bash
python tools/cli_debug.py [选项] [问题]

选项:
  --host HOST      服务地址 (默认: http://localhost:8002/api/v1)
  --debug          启用调试模式
  --raw            显示原始 JSON
  --no-color       禁用颜色输出
  -h, --help       显示帮助信息
```

### 环境变量

```bash
# 设置服务地址
export ALGORITHM_HOST=http://localhost:8002/api/v1

# 设置数据库路径
export DB_PATH=/path/to/database.db
```

## 故障排除

### 1. 无法连接到服务

```
❌ 无法连接到服务: http://localhost:8002/api/v1
ℹ️ 请确保服务已启动，或使用 --host 指定正确的地址
```

**解决方案：**
- 检查服务是否已启动：`python -m app.main`
- 检查服务地址是否正确：`--host http://localhost:8002/api/v1`
- 检查网络连接

### 2. SQL 执行错误

```
⚡ [SQL执行] SQL执行完成
   错误: no such table: xxx
```

**说明：**
- 这是正常的，因为 LLM 生成的表名可能与实际数据库不匹配
- 系统会自动处理错误并返回友好的提示

### 3. 流式响应中断

```
❌ 发送消息失败: Connection timeout
```

**解决方案：**
- 检查网络连接
- 增加超时时间（修改 `config.py` 中的 `timeout`）
- 重新发送请求

## 数据存储

CLI 工具的数据存储在后端服务的 SQLite 数据库中：

- **位置**: `algorithm-service/data/chat_history.db`
- **表结构**:
  - `chat_sessions`: 会话信息
  - `chat_messages`: 消息记录

## 高级用法

### 使用脚本批量查询

```bash
#!/bin/bash

QUESTIONS=(
    "查询最近7天的工单总量"
    "查询各地区的工单分布"
    "查询工单来源渠道统计"
)

for q in "${QUESTIONS[@]}"; do
    echo "查询: $q"
    python tools/cli_debug.py "$q"
    echo "---"
done
```

### 与管道结合使用

```bash
# 从文件读取问题并查询
cat questions.txt | xargs -I {} python tools/cli_debug.py "{}"

# 保存结果到文件
python tools/cli_debug.py "查询问题" 2>&1 | tee result.log
```
