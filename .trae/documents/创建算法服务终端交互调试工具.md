## 目标
创建一个独立的终端交互工具，用于调试算法服务

## 架构设计
```
tools/cli/
├── __init__.py
├── client.py       # HTTP客户端，处理SSE流式响应
├── renderer.py     # 终端渲染，颜色格式化输出
├── config.py       # 配置管理
└── interactive.py  # 交互式终端主程序
```

## 核心功能
1. **HTTP客户端** (`client.py`)
   - 发送POST请求到 /analyze 接口
   - 解析SSE流式响应
   - 处理连接错误和超时

2. **终端渲染** (`renderer.py`)
   - 不同事件类型用不同颜色显示
   - JSON格式化输出
   - 进度条/状态显示
   - 表格数据美化

3. **交互式终端** (`interactive.py`)
   - 连续提问模式
   - 命令支持 (/quit, /debug, /raw, /help)
   - 历史记录（上下键切换）
   - 自动补全

4. **配置管理** (`config.py`)
   - 服务地址配置
   - 默认数据源配置
   - 调试模式开关

## 文件清单
1. `tools/cli/__init__.py` - 包初始化
2. `tools/cli/config.py` - 配置管理
3. `tools/cli/client.py` - HTTP客户端
4. `tools/cli/renderer.py` - 终端渲染
5. `tools/cli/interactive.py` - 交互式终端主程序
6. `tools/cli_debug.py` - 入口脚本

## 使用方式
```bash
# 启动交互式终端
python tools/cli_debug.py

# 启动时指定服务地址
python tools/cli_debug.py --host http://localhost:8002

# 启用调试模式
python tools/cli_debug.py --debug
```
