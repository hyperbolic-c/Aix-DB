## 实现计划：术语和SQL样例存储功能

### 1. 扩展数据模型 (models.py)
- 新增 `Terminology` 模型：术语词条（术语名称、描述、分类）
- 新增 `SqlExample` 模型：SQL示例（问题、SQL、描述、数据源ID）

### 2. 扩展存储模块 (storage.py)
- 创建 `terminologies` 表：存储术语
- 创建 `sql_examples` 表：存储SQL示例
- 实现 CRUD 方法：
  - `add_terminology()` / `get_terminology()` / `list_terminologies()` / `delete_terminology()`
  - `add_sql_example()` / `get_sql_example()` / `list_sql_examples()` / `delete_sql_example()`

### 3. 扩展服务层 (service.py)
- 新增 `get_terminologies()` 方法：获取所有术语
- 新增 `get_sql_examples()` 方法：获取SQL示例
- 修改 `send_message()` 方法：在调用算法前读取术语和SQL示例，填充到请求体

### 4. 扩展客户端 (algorithm_client.py)
- 修改 `analyze()` 方法：增加 `terminologies` 和 `training_examples` 参数
- 从数据库读取后传入请求体

### 5. API路由 (router.py)
- 新增术语管理端点：`GET/POST/PUT/DELETE /api/v1/terminologies`
- 新增SQL示例端点：`GET/POST/PUT/DELETE /api/v1/sql-examples`
