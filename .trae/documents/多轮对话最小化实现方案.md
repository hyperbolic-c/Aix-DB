## 目标
为CLI工具添加多轮对话和会话管理功能

## 功能设计

### 新增命令
```
/new              - 创建新会话
/sessions         - 列出所有会话
/switch <id>      - 切换到指定会话
/history          - 显示当前会话历史
/clear_history    - 清空当前会话历史
```

### 自动功能
- 首次启动自动创建新会话
- 每条消息自动保存到当前会话
- 发送请求时自动携带历史记录

### 文件修改

1. **tools/cli/session_manager.py** (新增)
   - 会话管理类
   - 本地SQLite存储
   - 历史记录CRUD

2. **tools/cli/client.py** (修改)
   - 添加session_id参数
   - 发送请求时包含chat_history

3. **tools/cli/interactive.py** (修改)
   - 添加会话管理命令
   - 显示当前会话信息
   - 自动保存对话历史

4. **tools/cli/config.py** (修改)
   - 添加当前会话ID配置

### 数据存储
- 存储位置: `~/.algorithm_cli/chat_history.db`
- 表结构:
  - sessions: id, title, created_at, updated_at
  - messages: id, session_id, role, content, sql, timestamp

### 使用流程
```
> /new                    # 创建新会话
> 查询最近7天的工单量      # 第1轮
> 按地区分组显示           # 第2轮（自动携带上文）
> 只显示前3个地区          # 第3轮
> /history                # 查看完整历史
> /sessions               # 查看所有会话
> /switch 2               # 切换到会话2
```
